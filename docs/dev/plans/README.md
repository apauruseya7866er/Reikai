# Plans in flight

A plan is a design for work that is still being built. Once the work lands, its lasting content (how it works, invariants, decisions with their reasons) moves into the matching [subsystem doc](../subsystems/README.md) and the plan is deleted; git keeps the history. How each area works today is in [docs/dev/subsystems/](../subsystems/README.md), not here.

The template and the rule for what earns a plan live in [.claude/rules/roadmap-plans.md](../../../.claude/rules/roadmap-plans.md). The forward backlog is [ROADMAP.md](../../../ROADMAP.md).
